# gm-der

ASN.1 DER encoding/decoding primitives for GM (国密) cryptography.

This crate provides low-level DER (Distinguished Encoding Rules) serialization
helpers used by the other `gm-*` crates (certificates, keys, signed structures).
It is not typically used directly by applications.
